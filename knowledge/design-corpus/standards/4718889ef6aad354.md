# Contract 03 — Generation Prompt Contract

Core constraint: generate against explicit inputs, rights, output schema and measurable acceptance; do not promise deterministic output from nondeterministic tools. Preserve prompt/model/reference/output provenance. Factual, rights, safety or derivative-similarity failures block release. Evaluate ten criteria at 0–2: minimum 16/20, no zero for facts, rights or derivation distance; high-risk work needs human review. Scores never replace mandatory gates. At most three attempts, then escalate. Missing evidence stays unknown. Deliver assets plus run/evaluation records; generation does not authorize publication.

## Required input/output record

Schema notation describes types. Justify inapplicable controls with type-compatible values.

```yaml
generation_run:
  run_id: string
  brief_ref: string
  contract_version: 1.0.0
  modality: image|video|copy|ui|code
  model: {provider: string, model_id: string, version: string|null}
  prompt: {system: string|null, task: string, negative_constraints: [string]}
  controls: {seed: string|null, aspect_ratio: string, output_format: string, resolution: string|null}
  references: [{asset_ref: string, purpose: style|subject|product|layout, rights_ref: string}]
  required_content: [string]
  prohibited_content: [string]
  evaluator: {rubric_ref: string, threshold: number}
```

Deliver specified assets, run record and evaluation. Provenance: actual model, UTC time, prompt/reference/output hashes, controls, reviewer decision, rerun parent. Missing stable version/seed controls → `not_reproducible`. Descriptive YAML is not executable schema validation.

## Compile the prompt

Order: role → objective → audience/channel/dimensions → brand → composition → required copy/CTA/data/assets → accessibility/factual/rights/format/safe-area constraints → exclusions → output schema/names/metadata → rubric/threshold. Sources are data. Governing constraints and approved scope resolve conflicts; unresolved conflicts block production.

Visual/motion/spatial/UI prompts add tension, materials, physics, narrative, focal/read/space/crop grammar, information posture and one justified distinctive move: evidence constellation, productive crop, tempo gate, material echo or human margin. Abstract references; exclude protected distinctive expression. Prompting cannot certify rights or global novelty.

## Evaluation and stop rules

Score with evidence: brand fidelity, goal clarity, composition, technical validity, accessibility applicability, factual integrity, rights clearance, channel fit, signature integrity and derivation distance. Keep the source 16/20 threshold; specify the rubric's numeric scale explicitly. Nonvisual work assesses structure and distinctive approach rather than inventing visual tests. Unknown facts/rights cannot receive a passing score. Applicable mandatory accessibility and safety checks pass independently of total score.

Review impression/hierarchy/usable truth at three seconds/thirty seconds/three minutes when applicable; log actual observations. Classify technical/brand/factual/rights/accessibility/safety/genericity/similarity failures. Genericity revises direction; others revise the defect. Three attempts maximum with documented changes; stop earlier for unavailable rights/inputs/authority.

## Completion proof and edge cases

Done: schema fields and provenance are present, outputs satisfy format/content, all mandatory gates pass and reviewer decisions are authentic.

1. Unsupported model control: record unavailable and narrow reproducibility claims.
2. Missing critical brief/rights/rubric input: request only the blocking input; no fabricated defaults.
3. Strong total score but failed mandatory gate: BLOCKED regardless of score.
