# Contract 03 — Generation Prompt Contract

## Objective

Make image, video, copy, code, and multimodal generation inputs reproducible, evaluable, and rights-aware.

## Input schema

```yaml
generation_run:
  run_id: string
  brief_ref: string
  contract_version: 1.0.0
  modality: image|video|copy|ui|code
  model: {provider: string, model_id: string, version: string|null}
  prompt: {system: string|null, task: string, negative_constraints: [string]}
  controls: {seed: string|null, aspect_ratio: string, output_format: string, resolution: string|null}
  references: [{asset_ref: string, purpose: style|subject|product|layout, rights_ref: string}]
  required_content: [string]
  prohibited_content: [string]
  evaluator: {rubric_ref: string, threshold: number}
```

## Prompt structure

```text
ROLE: [expert role bounded to modality]
OBJECTIVE: [asset + business outcome]
AUDIENCE / CHANNEL: [who, where, dimensions]
BRAND INPUTS: [policy version, voice, visual tokens]
COMPOSITION: [reading order, subject, framing, lighting, camera or layout]
REQUIRED CONTENT: [copy, CTA, logo placement, data source]
CONSTRAINTS: [a11y, factual, rights, format, safe area]
EXCLUSIONS: [specific unwanted motifs and unsupported claims]
OUTPUT: [deliverable schema, filenames, metadata]
EVALUATION: [rubric and acceptance threshold]
```

## Evaluation rubric

Score 0–2 each: brand fidelity, goal clarity, composition, technical validity, accessibility applicability, factual integrity, rights clearance, and channel fit. Add signature integrity, where the declared tension and grammar are legible, and derivation distance, where the result remains materially distinct from reference assets. A release candidate needs at least 16/20, no zero in factual integrity, rights clearance, or derivation distance, and a human reviewer for high-risk content.

## Aesthetic compiler block

Use this block for prompts that create visual, motion, spatial, or interface work:

- Signature tension: force A held against force B.
- Material logic: how light, texture, surface, or depth behaves.
- Visual physics: gravity, opacity, scale shifts, edge behavior, and rhythm.
- Narrative movement: arrival, friction, evidence, participation, or resonance.
- Composition grammar: focal anchor, reading path, negative-space rule, and crop rule.
- Information posture: sparse, layered, instrumental, or ceremonial.
- Distinctive move: one original, repeatable design operation.

References supply only abstract inputs such as contrast, density, framing, palette temperature, pacing, and material cues. The prompt must require an original composition and exclude distinctive marks, layouts, characters, logos, and protected expression from references.

### Distinctive moves

| Move | Operation |
|---|---|
| Evidence constellation | Arrange proof, metadata, and annotation as the visual texture. |
| Productive crop | Use intentional partial framing to create attention without hiding required information. |
| Tempo gate | Alternate stillness and acceleration at defined narrative moments. |
| Material echo | Repeat one physical behavior across type, image, surface, and motion. |
| Human margin | Reserve an imperfect, human-scale region inside an otherwise systematic composition. |

The prompt explains how the chosen move serves the objective. The evaluator tests atmosphere at three seconds, hierarchy and point of view at thirty seconds, and usable detail and truthfulness at three minutes.

## Provenance record

Store model identifier, run timestamp UTC, prompt hash, reference hashes, controls, output hashes, evaluator result, reviewer decision, and rerun relationship. Record `not_reproducible` when a provider cannot supply stable versioning or seed control.

## Failure handling

Classify failures as technical, brand, factual, rights, accessibility, safety, genericity, or derivative similarity. Stop release for factual, rights, safety, or derivative-similarity failures; retain the failed run record and link the correction or rejection decision. Genericity triggers a revision of the Aesthetic Field or distinctive move.
