## Core constraint
Translate minimal dark developer communication with monospace accents into original design; validate usability and identity rights before implementation.

## 1. Visual Theme & Atmosphere
Source direction: minimal dark developer communication with monospace accents.

## 2. Color Palette & Roles
Observed: Void Black (#000000): Page background, the defining canvas color (95% opacity via --color-black-12). Near White (#f0f0f0): Primary text, button text, high-contrast elements. Pure White (#ffffff): --color-white, maximum emphasis text, link highlights.

## 3. Typography Rules
Observed: Display Hero: font domaine, size 96px (6.00rem), weight 400, line height 1.00 (tight), letter spacing 0.96px, notes "ss01", "ss04", "ss11". Display Hero Mobile: font domaine, size 76.8px (4.80rem), weight 400, line height 1.00 (tight), letter spacing 0.768px, notes Scaled for mobile.

## 4. Component Stylings
Observed: Text: #f0f0f0. Padding: 5px 12px. Radius: 9999px (full pill).

## 5. Layout Principles
Observed: Base unit: 8px. Scale: 1px, 2px, 4px, 5px, 6px, 7px, 8px, 10px, 12px, 16px, 20px, 24px, 30px, 32px, 40px. Single-column hero, expanding to feature grids below.

## 6. Depth & Elevation
Observed: Flat (Level 0): treatment No shadow, transparent background, use Default — most elements on dark void. Ring (Level 1): treatment rgba(176, 199, 217, 0.145) 0px 0px 0px 1px, use Shadow-as-border for cards, containers. Frost Border (Level 1b): treatment 1px solid rgba(214, 235, 253, 0.19), use Explicit borders — buttons, dividers, tabs.

## 7. Do's and Don'ts
Adapt source restrictions to the task; accessibility, semantic state, and authorized identity outrank style prescriptions.

## 8. Responsive Behavior
Observed: Mobile Small: width <480px, key changes Single column, tight padding, 76.8px hero. Mobile: width 480–600px, key changes Standard mobile, stacked layout. Desktop: width 600px, key changes Full layout, 96px hero, expanded sections.

## 9. Agent Prompt Guide
Derive an original screen specification from the brief; do not reproduce source brand copy, logos, imagery, or proprietary fonts.
