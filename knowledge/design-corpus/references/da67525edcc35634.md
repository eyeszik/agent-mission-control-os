## Core constraint

## 1. Visual Theme & Atmosphere
Source direction: reading-first documentation hierarchy with restrained atmospheric hero treatment.

## 2. Color Palette & Roles
Observed: Near Black (#0d0d0d): Primary text, headings, dark surfaces. Not pure black — the micro-softness improves reading comfort. Pure White (#ffffff): Page background, card surfaces, input backgrounds. Brand Green (#18E299): The signature accent — CTAs, links on hover, focus rings, brand identity.

## 3. Typography Rules
Observed: Display Hero: font Inter, size 64px (4.00rem), weight 600, line height 1.15 (tight), letter spacing 1.28px, notes Maximum impact, hero headlines. Section Heading: font Inter, size 40px (2.50rem), weight 600, line height 1.10 (tight), letter spacing 0.8px, notes Feature section titles.

## 4. Component Stylings
Observed: Background: #0d0d0d (near-black). Text: #ffffff. Padding: 8px 24px.

## 5. Layout Principles
Observed: Base unit: 8px. Scale: 2px, 4px, 5px, 6px, 7px, 8px, 10px, 12px, 16px, 24px, 32px, 48px, 64px. Section padding: 48px–96px vertical.

## 6. Depth & Elevation
Observed: Flat (Level 0): treatment No shadow, no border, use Page background, text blocks. Subtle Border (Level 1): treatment 1px solid rgba(0,0,0,0.05), use Standard card borders, dividers. Medium Border (Level 1b): treatment 1px solid rgba(0,0,0,0.08), use Interactive elements, input borders.

## 7. Dark Mode
Observed: Background: #0d0d0d (near-black). Text Primary: #ededed (near-white). Text Secondary: #a0a0a0 (muted gray).

## 8. Responsive Behavior
Observed: Mobile: width <768px, key changes Single column, stacked layout, hamburger nav. Tablet: width 768–1024px, key changes Two-column grids begin, expanded padding. Desktop: width 1024px, key changes Full layout, 3-column grids, maximum content width.

## 9. Agent Prompt Guide
Derive an original screen specification from the brief; do not reproduce source brand copy, logos, imagery, or proprietary fonts.
