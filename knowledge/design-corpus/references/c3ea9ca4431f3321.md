## 1. Visual Theme & Atmosphere
Source direction: warm editorial surfaces and orbital image relationships.

## 2. Color Palette & Roles
Observed: Mastercard Red (#EB001B): The left circle of the Mastercard mark — used only in the brand logo, never as a UI color. Mastercard Yellow (#F79E1B): The right circle of the Mastercard mark — used only in the brand logo, never as a UI color. Ink Black (#141413): The warm near-black used for primary CTAs, headline text on cream, and the footer surface. Slightly warm (the 13 blue value pulls toward the cream) so it never feels jet-black on the warm canvas.

## 3. Typography Rules
Observed: H1 (hero): size 64px, weight 500, line height 64px, letter spacing 1.28px (-2%), notes Set to 1:1 line-height for very tight vertical rhythm on multi-line hero. H2 (section): size 36px, weight 500, line height 44px, letter spacing 0.72px (-2%), notes Used in ghost-watermark headline treatments and section titles. H3 (card title): size 24px, weight 500, line height 28.8px (1.2), letter spacing 0.48px (-2%), notes Titles inside service/solution cards.

## 4. Component Stylings
Observed: Background: Ink Black (#141413). Text: Canvas Cream (#F3F0EE) — not pure white. Border: 1.5px solid Ink Black (same as bg, creates crisp edge).

## 5. Layout Principles
Observed: Base unit: 8px (confirmed by dembrandt extraction and computed styles). Section vertical padding: ~96–128px between major sections on desktop; ~48–64px on mobile. Card internal padding: 32–40px on desktop, ~24px on mobile.

## 6. Depth & Elevation
Observed: 0: treatment No shadow, use The default — 95% of surfaces sit directly on cream canvas. 1: treatment rgba(0, 0, 0, 0.04) 0px 4px 24px 0px, use Floating nav pill — barely-there lift. 2: treatment rgba(0, 0, 0, 0.08) 0px 24px 48px 0px, use Hero media frames, elevated cards — a soft large-radius halo rather than a hard drop.

## 7. Do's and Don'ts
Adapt source restrictions to the task; accessibility, semantic state, and authorized identity outrank style prescriptions.

## 8. Responsive Behavior
Observed: Mobile: width ≤ 767px, key changes Nav pill shows logo + menu + search only; primary links hide behind hamburger; service portraits stack single-column centered; hero headline drops from 64px to ~40px; footer columns collapse into a vertical accordion. Tablet: width 768–1023px, key changes Nav pill shows 2–3 primary links truncated; service portraits arrange 2-up; hero headline ~48px.
