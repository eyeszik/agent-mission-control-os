## 1. Visual Theme & Atmosphere
Source direction: light platform overview contrasted with darker technical reading sections.

## 2. Color Palette & Roles
Observed: Brand Magenta (#ef2cc1): The primary brand accent — a vivid pink-magenta used in gradient illustrations and the highest-signal brand moments. Never used as UI chrome. Brand Orange (#fc4c02): The secondary brand accent — a vivid orange for gradient endpoints and warm accent moments. Dark Blue (#010120): The primary dark surface — a deep midnight blue-black used for research sections, footer, and dark containers. Not gray, not black — distinctly blue.

## 3. Typography Rules
Observed: Display / Hero: font The Future, size 64px (4rem), weight 400–500, line height 1.00–1.10 (tight), letter spacing 1.92px, notes Maximum impact, dense blocks. Section Heading: font The Future, size 40px (2.5rem), weight 500, line height 1.20 (tight), letter spacing 0.8px, notes Feature section titles.

## 4. Component Stylings
Observed: Text: Pure White (#ffffff). Radius: sharp (4px). Background: Dark Blue (#010120) or Pure Black.

## 5. Layout Principles
Observed: Base unit: 8px. Scale: 1px, 2px, 4px, 8px, 10px, 12px, 16px, 20px, 24px, 32px, 44px, 48px, 80px, 100px, 120px. Button/badge padding: 2px 8px (compact).

## 6. Depth & Elevation
Observed: Flat (Level 0): treatment No shadow, no border, use Page background, text blocks. Contained (Level 1): treatment 1px solid rgba(0,0,0,0.08) (light) or rgba(255,255,255,0.12) (dark), use Cards, badges, containers. Elevated (Level 2): treatment rgba(1, 1, 32, 0.1) 0px 4px 10px, use Feature cards, hover states.

## 7. Do's and Don'ts
Adapt source restrictions to the task; accessibility, semantic state, and authorized identity outrank style prescriptions.

## 8. Responsive Behavior
Observed: Mobile: width <479px, key changes Compact layout, stacked everything. Large Mobile: width 479–767px, key changes Single column, hamburger nav. Tablet: width 768–991px, key changes 2-column grids begin.
