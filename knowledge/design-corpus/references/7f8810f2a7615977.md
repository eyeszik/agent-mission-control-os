## Core constraint
Translate product photography with minimal, legible purchase navigation into original design; validate usability and identity rights before implementation.

## 1. Visual Theme & Atmosphere
Source direction: product photography with minimal, legible purchase navigation.

## 2. Color Palette & Roles
Observed: Electric Blue (#3E6AE1): Primary CTA button background — a confident, mid-saturation blue (rgb 62, 106, 225) that stands alone as the only chromatic color in the entire interface. Used exclusively for "Order Now" and other primary action buttons. Pure White (#FFFFFF): Dominant background color for all surfaces, panels, navigation, and secondary button fills — the canvas that lets photography breathe.

## 3. Typography Rules
Observed: Hero Title: size 40px (2.50rem), weight 500, line height 48px (1.20), letter spacing normal, notes Universal Sans Display, white on dark hero imagery. Product Name: size 17px (1.06rem), weight 500, line height 20px (1.18), letter spacing normal, notes Universal Sans Text, model names in nav panel and cards. Nav Item: size 14px (0.88rem), weight 500, line height 16.8px (1.20), letter spacing normal, notes Universal Sans Text, primary navigation labels.

## 4. Component Stylings
Observed: Default: bg #3E6AE1 (Electric Blue), text #FFFFFF, fontSize 14px, fontWeight 500, padding 4px with inner content centering, borderRadius 4px, minHeight 40px, width 200px. Border: 3px solid transparent (reserves space for focus/active border animation). Box Shadow: rgba(0,0,0,0) 0px 0px 0px 2px inset (invisible at rest, animates to visible on focus).

## 5. Layout Principles
Observed: Base unit: 8px. Common values: 8px (0.5rem), 16px (1rem), 21.44px (1.34rem). Button padding: 4px (minimal outer) with content centering via flexbox, 4px 16px for nav items.

## 6. Depth & Elevation
Observed: Level 0 (Flat): treatment No shadow, no border, use Default state for all elements — cards, panels, buttons at rest. Level 3 (Subtle): treatment rgba(0,0,0,0.05), use Minimal shadow hints on rare hover states. The hero imagery itself provides all visual richness — sunset skies, reflected light on car surfaces, ground shadows from studio lighting.

## 7. Do's and Don'ts
Adapt source restrictions to the task; accessibility, semantic state, and authorized identity outrank style prescriptions.

## 8. Responsive Behavior
Observed: Mobile: width <768px, key changes Single-column layout, hamburger nav replaces horizontal labels, hero text scales to ~28px, CTA buttons stack vertically, category cards become full-width. Tablet: width 768-1024px, key changes 2-column nav panel, hero maintains full-viewport height, CTAs remain side-by-side, reduced horizontal padding. Desktop: width 1024-1440px, key changes Full horizontal nav, 3-column vehicle grid in dropdown, hero at 40px, side-by-side CTAs at 200px/160px width.
