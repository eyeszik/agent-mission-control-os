## 1. Visual Theme & Atmosphere
Source direction: enterprise clarity through rounded containment and editorial/display contrast.

## 2. Color Palette & Roles
Observed: Cohere Black (#000000): Primary headline text and maximum-emphasis elements. Near Black (#212121): Standard body link color — slightly softer than pure black. Deep Dark (#17171c): A blue-tinted near-black for navigation and dark-section text.

## 3. Typography Rules
Observed: Icons: CohereIconDefault (custom icon font). Display / Hero: font CohereText, size 72px (4.5rem), weight 400, line height 1.00 (tight), letter spacing 1.44px, notes Maximum impact, serif authority.

## 4. Component Stylings
Observed: Text: Cohere Black (#000000). Hover: text shifts to Interaction Blue (#1863dc), opacity 0.8. Focus: solid 2px outline in Interaction Blue.

## 5. Layout Principles
Observed: Base unit: 8px. Scale: 2px, 6px, 8px, 10px, 12px, 16px, 20px, 22px, 24px, 28px, 32px, 36px, 40px, 56px, 60px. Card internal padding: approximately 24–32px.

## 6. Depth & Elevation
Observed: Flat (Level 0): treatment No shadow, no border, use Page background, text blocks. Bordered (Level 1): treatment 1px solid #f2f2f2 or #d9d9dd, use Standard cards, list separators. *Shadow Philosophy: Cohere is nearly shadow-free. Depth is communicated through background color contrast (white cards on purple bands, white surface on snow), border containment (cool gray borders), and the dramatic light-to-dark section alternation. When elements need elevation, they achieve it through being white-on-dark rather than through shadow casting.

## 7. Do's and Don'ts
Adapt source restrictions to the task; accessibility, semantic state, and authorized identity outrank style prescriptions.

## 8. Responsive Behavior
Observed: Small Mobile: width <425px, key changes Compact layout, minimal spacing. Mobile: width 425–640px, key changes Single column, stacked cards. Large Mobile: width 640–768px, key changes Minor spacing adjustments.

## 9. Agent Prompt Guide
Derive an original screen specification from the brief; do not reproduce source brand copy, logos, imagery, or proprietary fonts.
