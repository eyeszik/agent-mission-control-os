# Design System Inspired by OpenCode

> Category: AI & LLM

## Core constraint
Translate warm terminal atmosphere with consistent monospace hierarchy into original design; validate usability and identity rights before implementation.

## 1. Visual Theme & Atmosphere
Source direction: warm terminal atmosphere with consistent monospace hierarchy.

## 2. Color Palette & Roles
Observed: OpenCode Dark (#201d1d): Primary background, button fills, link text. A warm near-black with subtle reddish-brown warmth -- rgb(32, 29, 29). OpenCode Light (#fdfcfc): Primary text on dark surfaces, button text. A barely-warm off-white that avoids clinical pure white. Mid Gray (#9a9898): Secondary text, muted links. A neutral warm gray that bridges dark and light.

## 3. Typography Rules
Observed: Heading 1: size 38px (2.38rem), weight 700, line height 1.50, notes Hero headlines, page titles. Heading 2: size 16px (1.00rem), weight 700, line height 1.50, notes Section titles, bold emphasis. Body: size 16px (1.00rem), weight 400, line height 1.50, notes Standard body text, paragraphs.

## 4. Component Stylings
Observed: Background: #201d1d (OpenCode Dark). Text: #fdfcfc (OpenCode Light). Padding: 4px 20px.

## 5. Layout Principles
Observed: Base unit: 8px. Fine scale: 1px, 2px, 4px (sub-8px for borders and micro-adjustments). Standard scale: 8px, 12px, 16px, 20px, 24px.

## 6. Depth & Elevation
Observed: Flat (Level 0): treatment No shadow, no border, use Default state for most elements. Border Subtle (Level 1): treatment 1px solid rgba(15, 0, 0, 0.12), use Section dividers, input borders, horizontal rules. Border Tab (Level 2): treatment 2px solid #9a9898 bottom only, use Active tab indicator.

## 7. Interaction & Motion
Observed: Links: color shift from default to accent blue (#007aff) or underline style change. Accent blue provides a three-stage hover sequence: #007aff → #0056b3 → #004085 (default → hover → active). Danger red: #ff3b30 → #d70015 → #a50011.

## 8. Responsive Behavior
Observed: Mobile: width <640px, key changes Single column, reduced padding, heading scales down. Tablet: width 640-1024px, key changes Content width expands, slight padding increase. Desktop: width 1024px, key changes Full content width (~800-900px centered), maximum whitespace.

## 9. Agent Prompt Guide
Derive an original screen specification from the brief; do not reproduce source brand copy, logos, imagery, or proprietary fonts.
