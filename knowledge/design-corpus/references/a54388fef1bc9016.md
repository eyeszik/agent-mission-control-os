## 1. Visual Theme & Atmosphere
Source direction: cinematic commerce hierarchy with ultralight display and selective luminous accents.

## 2. Color Palette & Roles
Observed: Shopify White (#FFFFFF): Primary text on dark surfaces, button fills, high-contrast elements. Shopify Black (#000000): Body background, button text on white, maximum contrast base (--color-shade-100). Neon Green (#36F4A4): The signature accent — focus rings, interactive highlights, active state indicators. Electric and bioluminescent.

## 3. Typography Rules
Observed: Display XL: size 96px, weight 400, line height 1.00, notes NeueHaasGrotesk, hero headlines, "ss03". Display XL Bold: size 90.74px, weight 750, line height 1.00, letter spacing 4.54px, notes NeueHaasGrotesk, emphasis display. Display XL Tracked: size 96px, weight 400, line height 1.00, letter spacing 2.4px, notes NeueHaasGrotesk, spaced display.

## 4. Component Stylings
Observed: Background: White (#FFFFFF). Text: Black (#000000). Border: 2px solid transparent.

## 5. Layout Principles
Observed: space-1: value 4px, use Tight inline gaps. space-2: value 8px, use Base unit, icon gaps. space-3: value 12px, use Card padding, tight margins.

## 6. Depth & Elevation
Observed: Base: treatment No shadow, dark surface, use Default page background. Subtle: treatment rgba(0,0,0,0.1) 0px 0px 0px 1px + inset white glow, use Resting cards. Medium: treatment Multi-layer: 1px ring + 2px + 4px + 8px shadow stack, use Elevated cards, featured sections.

## 7. Do's and Don'ts

## 8. Responsive Behavior
Observed: Mobile: width <640px, key changes Single column, hamburger nav, display text scales to 48px, 16px padding. Tablet: width 640-1024px, key changes 2-column grids begin, display text at 70px, 32px padding. Desktop: width 1024-1440px, key changes Full layout, expanded nav, 96px display, 64px padding.
