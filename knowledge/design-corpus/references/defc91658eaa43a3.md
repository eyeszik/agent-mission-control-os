## 2. Color Palette & Roles
Observed: Composio Cobalt (#0007cd): The core brand color — a deep, saturated blue used sparingly for high-priority interactive elements and brand moments. It anchors the identity with quiet intensity. Electric Cyan (#00ffff): The attention-grabbing accent — used at low opacity (rgba(0,255,255,0.12)) for glowing button backgrounds and card highlights. At full saturation, it serves as the energetic counterpoint to the dark canvas.

## 3. Typography Rules
Observed: Display / Hero: font abcDiatype, size 64px (4rem), weight 400, line height 0.87 (ultra-tight), letter spacing normal, notes Massive, compressed headings. Section Heading: font abcDiatype, size 48px (3rem), weight 400, line height 1.00 (tight), letter spacing normal, notes Major feature section titles.

## 4. Component Stylings

## 8. Responsive Behavior
Observed: Mobile: width <768px, key changes Single column, hamburger nav, full-width cards, reduced section padding, hero text scales down to ~28-40px. Tablet: width 768-1024px, key changes 2-column grid for cards, condensed nav, slightly reduced hero text. Desktop: width 1024-1440px, key changes Full multi-column layout, expanded nav with all links visible, large hero typography (64px).
