# Brand programs

Each directory is one governed brand program: the prompt that started it, the
evidence it rests on, the decision ledger, and (after approval only) the
generated identity artefacts.

| Program | Business | Status | Gate |
| --- | --- | --- | --- |
| [`unsplit/`](unsplit/) | A zero-touch atelier that turns a year of running into one printed line. | Draft v0.1 | `CD-001` creative direction **OPEN** |

## Rules these programs follow

1. **The prompt is an artefact.** It is versioned, reusable and states its own
   hard rules.
2. **Evidence carries a URL and an access date.** Secondary sources are labelled
   as secondary. Market size is never presented as demand.
3. **Assumptions are named and testable.** They are not buried in prose.
4. **A recommendation is not a decision.** Drafting agents write options; humans
   record approvals in `decisions.md`.
5. **Nothing is generated before the creative-direction gate**, and no asset is
   called verified until it has been read back from storage and re-hashed.
6. **A blocked capability is reported, not simulated.** If Chromium, FFmpeg or
   Blender is absent, the deliverable is `BLOCKED` with the exact dependency
   named.
7. **No publishing, sending, deploying, purchasing or spending** is performed by
   a brand program.
