## Re-audit 2026-11-10 — audited frontend baseline re-pinned to Next.js 16.4.5 / @playwright/test 1.65.0

Dependabot #225 (next 16.4.3→16.4.5) and #239 (@playwright/test 1.64.1→1.65.0) merged the
November 2026 security releases ahead of this document's 16.4.3 baseline while the `CI`
workflow could not run at all (the repository Actions allow-list rejected `pnpm/action-setup`;
every `CI` run died at startup from 2026-11-08). Re-baselined rather than reverted, because
16.4.3 is affected by seven published advisories fixed in 16.4.5 — including GHSA-mfr8-8qww-v76h
(High, cross-tenant cache disclosure via `unstable_cache`/`use cache`), GHSA-vc7v-qv4w-wrv8,
GHSA-rhh4-g77r-r9qj, GHSA-vvgp-ww4w-46vf, GHSA-pc58-hwjq-p385, GHSA-7qx7-33qx-rqx2 (SVG
rejection bypass), GHSA-f3mh-rxg3-f5g2 (HttpOnly cookie exposure on Edge routes). Reverting
would reintroduce published vulnerabilities. @playwright/test 1.65.0 has no known
vulnerabilities (test-runner only); the `retries: 0` / `workers: 1` release-gate invariants are
unchanged, and pins in `scripts/verify_repository_invariants.py`, `services/langgraph/agency/
