## Generation policy and receipts

A live brief must be explicitly selected. Preparing generation writes an immutable
`unbound-generation-plan/v1` research artifact with the source artifact/version/hash,
brief hash, single pinned model profile, schema and prompt versions. It opens an
`INNOVATION_GENERATION` approval through the existing authority, bound to exact plan
bytes and purpose. It is not creative artifact-release approval. Local self-approval
overrides do not authorize this new generation purpose.

The generation job uses canonical durable ticks and NON_RETRYABLE intents. One call
only: no provider fallback, no silent fixture substitution, no retry of unknown remote
outcomes. The call is outside a database transaction. Reconciliation preserves unknown
state rather than dispatching again. Rechecks cover source version, cancellation/pause,
profile revocation, current approval scope/purpose/hash/version and provider eligibility.
Known output is hash-verified and stored independently; an obsolete output cannot be
promoted as current. Interrupted-call recovery without a known provider receipt remains
blocked and requires explicit investigation, not another paid call.

Initial eligible route is local Ollama only, using its existing loopback API. Remote
providers remain `REMOTE_SPEND_POLICY_GAP` even when a credential exists: this feature
has no verified price/paid-spend enforcement. The signed-off plan permits zero paid API
cost, one call, 8192 output tokens, 60000 prompt bytes and a 30-second HTTP timeout.
Byte and output caps are not a calibrated model context-window estimate. Total wall
execution may include validation/persistence; cancellation does not promise remote
request abortion. A server-configured model is not proof that it is installed or running.

The canonical Ollama dialect now forwards `options.num_predict` and JSON `format`, and
refuses `done_reason=length` as terminal truncation. Primary source inspected:
[Ollama chat API](https://docs.ollama.com/api/chat). This fixes output caps that the earlier
Ollama path accepted as arguments but did not send. Other provider dialects are preserved.

Raw ideas remain HYPOTHESIS/MODEL_GENERATED. Unique mechanism normalization and full lens
coverage are structural gates. No embedding threshold, semantic originality, brief relevance
pilot, independent evaluator calibration or >=0.85 release confidence was measured.
A valid raw cohort does not complete synthesis, research, evaluation, experiments or release.

## Actual local experiment and learning

A completed, disclosed v1 simulation can feed a fixed lexical-normalization experiment.
35 authored mechanisms plus four disclosed case/whitespace variants are inputs. The
preregistered comparator is exact-string deduplication; candidate normalization uses
casefold/whitespace equivalence. Metrics count retained redundant representations, not
relevance or market outcomes. Bounds: at most 64 strings, each at most 2000 characters,
fixed code, no model/network/subprocess/generated code. No sandbox isolation claim is needed
or made for executing this fixed trusted arithmetic/string algorithm.

Measurements are computed through the canonical fabric. The persisted chain connects
source version/hash → immutable plan/input hash → permit → executor version → stored output
→ execution/observation receipts → deterministic interpretation/learning. Repeated requests
reuse the same identity; changed source versions or bytes refuse stale observations.
Original concepts and hypotheses are not overwritten. Release remains unauthorized.
Internal input facts support only this local audit; they are not external research sources.

## Operations and recovery

Select Simulation or Live at brief creation. Simulation remains explicitly labeled.
For Live, prepare the intent in the mobile UI, inspect target/hash/budget and blockers,
and request a distinct authorized reviewer through the existing approval mechanism.
Do not paste credentials into chat or briefs. Configure an approved local provider using
the established environment workflow. An approval cannot make missing hardware/models or
unsupported remote-spend policy available. Advance performs an explicit bounded tick;
there is no active background scheduler claim.

For a completed simulation, run the local lexical experiment and inspect its receipts
and learning history separately from the simulated score. A refreshed page reloads
persisted records. Never relabel the source run as live.

For an unknown model outcome, inspect the canonical durable intent and receipt; do not
reset the job or blindly retry. Rejected/expired/stale approvals do not transfer to a
changed request. Preserve old generation/experiment artifacts; recreate a new scoped run
for a changed brief/profile until full minimal-rebuild orchestration is implemented.

Rollback: revert the incremental commit(s), retain canonical historical artifacts and
approvals, refresh affected Git-blob manifest pins with scripts.verify_manifest.git_blob_sha,
and run all seven gates plus v1 regression tests. No SQL migration rollback is needed.
Production deployment remains a separate, approval-dependent runbook stage.
