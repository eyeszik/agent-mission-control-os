## 2024-08-08 - Zustand Selector Re-render Anti-Pattern
**Learning:** Extracting full state objects (like `Object.values(state.approvals)`) from Zustand stores and performing derived computations (like `.filter().length`) directly inside the React component body is a common anti-pattern in this codebase. It causes the component to re-render whenever ANY value in the state object changes, even if the derived result remains the same.
**Action:** When extracting derived data from Zustand, perform the calculation *inside* the selector function (e.g., `useApprovalStore(state => Object.values(state.approvals).filter(a => a.status === 'pending').length)`). For selectors returning arrays or objects that represent equivalent state despite reference changes, always wrap the selector in `useShallow` from `zustand/react/shallow`.
