## 2024-09-11 - Avoid Re-renders via Derived Selectors and Hoisted Arrays
**Learning:** Zustand selectors that return entire arrays (like `state.artifacts[runId]`) cause components to re-render on every background append, even if the specific item the component renders hasn't changed. Additionally, dynamic array slicing and mapping (e.g., `.slice().map()`) inside a render function creates unnecessary garbage collection on every state update.
**Action:** Compute derived state (such as `.find()`) directly inside Zustand selectors so the returned object reference remains strictly equal (`===`), preventing re-renders. Hoist static layout calculations and array mappings outside of React components entirely.
