# agency/sop

## Ordered SOP contracts — a guard over the live graph, not an authority

`services/langgraph/agency/sop/` + `graph/agency/build.py` (every node wrapped by `guard_stage`) + `packages/shared/src/schemas/sop.ts` (`docs/acceptance-closure.md`):

- **One registry.** `data/sop_registry.v1.json` is the single source. Pydantic (`contracts.py`) and Zod (`sop.ts`) validate the same bytes; the TS fixture `packages/shared/tests/fixtures/sop-registry.json` is regenerated with `AMC_REGENERATE_FIXTURES=1 pytest services/langgraph/tests/test_sop_contracts.py`.
- **Order follows the topology.** Pipeline procedures must equal `agency/delivery/workflow.topology()` for every workflow version; add a stage there and here together. `sequence_index` is contiguous from 1, no step repeats, and a step may only require state an earlier step produced (`verify_repository_invariants.py` checks this statically).
- **References are proof, checked.** `enforced_by` and `tests` are `path::symbol`; `verify_against_code()` resolves every one, plus N3 owner roles, `LIVE_STAGE_ARTIFACTS` production rights and the RoleOS skill from `AGENCY_STAGE_BINDINGS`. Never cite a symbol or test that doesn't exist.
- **Guard semantics.** Missing entry state or a dropped declared output raises `SopContractViolation`; the run fails. The guard is behaviour, not topology, so `graph_fingerprint` is unchanged — never add or reorder nodes through it.
- **Failure disposition** is `FALLBACK_DEGRADED` or `BLOCKED`, never a pass. The registry grants no authority; approval and release stay on `/approvals/{id}/decide` and the N2 release guards.
- **Brand OS 4.0 index and drafts.** `data/brand_os_index.v1.json` declares F01-F60 (ids, names, departments: an owner declaration, never procedure text); `brand_os_source.py` validates it. F01-F08 point at newly written drafts in `data/brand_os/` (origin `NEWLY_AUTHORED_SOP`, v0.1-draft), pinned by the SHA-256 of their bytes; F09-F60 are `SOURCE_UNAVAILABLE`. The Brand OS 3.0 originals were never recovered: never label a draft as an original, and never edit a draft in place (a change is a new file and a new digest). `test_sop_brand_os_source.py` re-hashes every draft.
- **Approval (Batch 1b), two purposes that never satisfy each other.** `source_approval.py`: `BRAND_OS_SOURCE` asks whether stored bytes are the *original* procedure (`open_source_approval` refuses any newly written draft); `BRAND_OS_SOP_ADOPTION` adopts a newly written draft for one project (`stage_sop_for_adoption` stores the pinned bytes as a `knowledge_capsule` under `market_researcher` via `foundry.studio.store` and opens the approval via `open_artifact_approval`). At most one approval per tenant, project, artifact and purpose may be pending; a partial unique index enforces it (`20261122_amc_brand_os_pending_approval_unique_v1.sql`, SQLite `idx_approvals_brand_os_pending`). A lost race re-reads the winner, and different content is a 409; don't replace this with a process-local lock. Both are decided only on `/approvals/{id}/decide` by someone other than the requester, and verified by `verify_source_approval` / `verify_sop_adoption` over `artifact_release_verdict` plus purpose and principal-scope checks. They return evidence (`grants_runtime_authority` is typed `False`), never a token, and never decide or release anything.
- **Companion, mapping and API.** `data/brand_os_companion.v1.json` (ADVISORY per-step operating detail; never adopted content, never a role grant) and `data/brand_os_agm_mapping.v1.json` (63 steps against the pinned AGM catalog: 54 PARTIAL_MATCH, 9 UNRESOLVED) are keyed by SOP id, pinned source digest and step ref `F0n.Sk`; `companion_problems()` / `mapping_problems()` fail on any drift from the drafts, the catalog or N3 roles. `/brand-os` (`api/routes/brand_os.py`, `brand_os_service.py`) lists SOPs and requests/reads per-project adoption (operator role + `Idempotency-Key`; decisions stay on `/approvals/{id}/decide`). Contracts: `brand_os_contracts.py` with Zod twin `packages/shared/src/schemas/brandOs.ts`; fixture `packages/shared/tests/fixtures/brand-os.json` (regenerate with `AMC_REGENERATE_FIXTURES=1 pytest services/langgraph/tests/test_brand_os_api.py`).
